## Local convention

After legally obtaining a book, an optional local copy can be named `books/<ALIAS>.pdf`, for example `books/DDIA.pdf`. These PDFs are ignored by Git and are never part of the public repository.

The schedulers operate on `glossaries/` and `schedule/`; they do not require the PDFs to run.
