# db-from-scratch

Long-term learning repository for building database internals from first
principles.

## Structure

- `core/`: canonical educational database engine
- `labs/`: isolated experiments and alternate designs
- `references/`: study notes from upstream systems
- `docs/`: specs, plans, and milestone notes
- `external/`: local clones of upstream reference databases

## Reference Codebases

- PostgreSQL: storage, WAL, MVCC, recovery, concurrency, engineering discipline
- DuckDB: vectorized execution, columnar processing, OLAP-focused design
