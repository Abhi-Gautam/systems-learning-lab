# 08 — LC 155 Min Stack

LeetCode 155. Implement `push`, `pop`, `top`, and `getMin`, all O(1). Use your
own linked nodes. Store enough per-node state to recover the minimum after pop;
do not scan the stack and do not use STL containers. Empty behavior is not called
by the original judge, but make it explicit in your comments.
