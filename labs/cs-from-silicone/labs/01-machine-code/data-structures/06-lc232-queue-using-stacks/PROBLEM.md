# 06 — LC 232 Implement Queue using Stacks

LeetCode 232. Implement a FIFO queue using two DIY LIFO stacks. API: `push`,
`pop`, `peek`, `empty`. Do not use `std::stack`; each stack must be your own
linked nodes. Target amortized O(1) per operation using input/output stacks.
State and test the transfer invariant.

make test-06-lc232-queue-using-stacks
