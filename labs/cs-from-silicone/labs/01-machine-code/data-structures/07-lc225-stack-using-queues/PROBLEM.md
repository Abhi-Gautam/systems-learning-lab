# 07 — LC 225 Implement Stack using Queues

LeetCode 225. Implement LIFO stack API `push`, `pop`, `top`, `empty` using your
own linked FIFO queues. No `std::queue`. Choose one or two queues and document
the invariant. Target either O(1) push/O(n) pop or O(n) push/O(1) pop.

make test-07-lc225-stack-using-queues
