# 11 — LC 706 Design HashMap

LeetCode 706. Implement `put(key,value)`, `get(key)` (-1 absent), and `remove(key)`
using bucket chains of your own key/value nodes. No unordered_map. Handle update
without duplicate keys. Start with fixed buckets, then add resizing as an explicit
second milestone. Explain modulo for non-negative LC keys.
