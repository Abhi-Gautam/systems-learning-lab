# 17 — LC 895 Maximum Frequency Stack

LeetCode 895. Implement `push(x)` and `pop()` returning the most frequent value;
ties go to most recently pushed. Compose a homemade key->frequency hash index and
a frequency->stack-of-nodes structure. No STL containers. Target O(1) average.

## Run

```bash
make test-17-lc895-max-freq-stack
make test-17-lc895-max-freq-stack ASAN=1
```
