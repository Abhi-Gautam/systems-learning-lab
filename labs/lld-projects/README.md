# Active LLD projects

This directory contains only implementations written during the new interview-learning flow.

- Create one folder only when an LLD lab is assigned.
- Start from the assignment brief; do not copy architecture or code from prior solutions.
- Put the primary Go implementation here. Add C++ only for selected language-transfer exercises.
- Share the completed folder for design, correctness, concurrency, lifecycle, and testability review.

Old generated solution skeletons are archived at `../lld-reference-archive/` and are not part of the active curriculum.
